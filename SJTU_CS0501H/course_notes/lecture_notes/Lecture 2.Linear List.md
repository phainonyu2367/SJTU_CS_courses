## 引入
考虑一个一元多项式，我们希望用一个结构来存储一元多项式的数据。事实上，我们需要储存的内容就包括一元多项式的系数和次数，一个比较简单的想法就是，我们通过数组来存储一元多项式，下标表示次数，值表示系数，这样就可以比较好地表示一元多项式，并进行相关的运算。

可以实现类似的效果
```
int* polyterm = new int[3];
for (int i = 0; i < 3; i++) {
	std::cin >> polyterm[i];
}
```

但是这样有一个问题，数组的size是固定不变的，如果该多项式的中间某些项为0，那么这个数组在事实上就造成了浪费。而且，在实际生活中，我们往往也不会只用固定上限的一元多项式。

所以，为了节省空间，我们可以只储存有用的值来实现一元多项式的表示

我们考虑这样的一个结构，用一个struct来储存某一项的系数和指数，按顺序构建，调用的方便程度大大提高。(于此同时解决了存储效率的问题)

```
struct Node {
	int coefficient;
	int exposure
}
```

但是这样子来写，仍然存在一个问题，就是数组上限的问题仍然没有解决

所以最后我们选择使用链表来实现存储

## 线性表
线性表时有同类型的数据元素构成的有序序列
- 表中元素的个数为线性表的长度
- 没有元素时我们称为空表
- 线性表起始位置我们称为开头

>ADT(Abstract Data Type)
